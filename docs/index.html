01

Why Centre

Stop rebuilding the same desktop.

Applications do not always reopen at useful sizes or positions. Centre turns a layout you already like into a repeatable workflow.

⌁

Capture once, restore anytime

Save the active application's exact coordinates and dimensions. Capture it again whenever you want to replace that preset.

Ctrl+Alt+P
▦

Full workspace restore

Move every matching open application with one shortcut.

↻

Live configuration

Valid presets, ignored applications, and logging changes load while the listener is running.

◎

Layouts follow the current display resolution

Keep separate preset collections for different resolutions, with explicit left, top, width, and height values.

1920 × 1080
02

Quick start

From install to restored layout.

Three steps are enough to begin using Centre.

1

Install the package

Centre requires Windows and Python 3.10 or later.

pip install centre
2

Start the listener

Keep this process running to enable shortcuts. Centre creates its configuration file automatically on first start. Only one listener can run in the current Windows login session.

centre -s
3

Capture and restore

Arrange a window, press Ctrl+Alt+P to capture it, then press Ctrl+Alt+D whenever it needs restoring.

CaptureCtrl+Alt+P RestoreCtrl+Alt+D
i

Updating Centre? Run pip install -U centre to install the latest available release.

03

Keyboard shortcuts

Everything stays within reach.

These defaults can be changed in config.json.

Action What it does Shortcut
Center Apply the named preset or Default_Position. Ctrl+Alt+D
Minimize Minimize the active window. Ctrl+Alt+M
Capture Save or update the active application's preset. Ctrl+Alt+P
Ignore Add the active application to ignored_presets. Ctrl+Alt+I
Center all Apply named presets to all matching open windows. Ctrl+Alt+A
04

Preset behavior

Predictable rules, no hidden state.

Centre identifies applications by executable name and stores plain JSON.

01

Executable-based names

Names are uppercase without .exe: WindowsTerminal.exe becomes WINDOWSTERMINAL.

02

Capture updates existing presets

Capturing the same application again replaces its position and size under the current display resolution.

03

Ignore is not a toggle

Ctrl+Alt+I adds the executable to ignored_presets. Remove it from the JSON file to manage that application again.

04

Center-all uses named presets only

It does not apply Default_Position and skips any executable in ignored_presets, even when a named preset exists.

config.json 
{
  "presets": {
    "1920x1080": {
      "WINDOWSTERMINAL": {
        "LEFT": 0,
        "TOP": 0,
        "SIZE_X": 1280,
        "SIZE_Y": 1080
      },
      "Default_Position": {
        "LEFT": 320,
        "TOP": 120,
        "SIZE_X": 1280,
        "SIZE_Y": 800
      }
    }
  },
  "predefined_keybindings": {
    "enabled": true,
    "bindings": {
      "center": "ctrl+alt+d",
      "minimize": "ctrl+alt+m",
      "capture": "ctrl+alt+p",
      "ignore_preset": "ctrl+alt+i",
      "center_all": "ctrl+alt+a"
    }
  },
  "logging": false,
  "ignored_presets": []
}
05

Configuration file

Readable, editable, and watched live.

Back up or version the file like any other plain-text configuration.

⌂
Configuration location %USERPROFILE%\.centre\config.json
Per-resolution presets

Each resolution key owns a separate collection of application positions.

Automatic validation

Unknown predefined shortcut names and unexpected fields are rejected.

Live reload

Valid preset, ignore-list, and logging changes apply while Centre runs.

Default migration

Missing fields with defaults are added and written back to the file.

Configurable logging

Set logging to true to write activity and errors to centre.log.

Invalid config is fatal

An invalid startup or live configuration stops Centre instead of continuing with uncertain settings.

i

Shortcut changes require a restart. Centre reloads the configuration file live, but keyboard hooks are registered when the listener starts. Stop and restart centre -s after editing a shortcut.

!

If a saved configuration is invalid, Centre performs an orderly shutdown. Correct config.json, then run centre -s again.

≡
Optional log file %USERPROFILE%\.centre\centre.log

File logging is disabled by default. When enabled, Centre appends timestamped activity and error entries to centre.log. Changing logging back to false closes the file handler. The file is not automatically rotated or deleted.

06

CLI reference

One action at a time.

Start Centre or inspect its current state. Action flags are mutually exclusive, so each invocation accepts only one action.

centre -s
StartStart the listener and enable shortcuts.
centre -l
ListList open windows, sizes, and positions.
centre -c
Read configPrint the loaded configuration.
centre -v
VersionPrint the installed Centre version.
centre -h
HelpShow all available command-line options.
i

The listener is single-instance. Starting a second centre -s in the same Windows login session prints Centre already running and exits before loading configuration. The list, config, version, and help commands remain available.

!

To stop an interactive listener, press Ctrl+C. Centre removes its keyboard hooks and stops its configuration observer before exiting.

07

Automatic startup

Have Centre ready when you log on.

Create a lightweight Windows Task Scheduler entry with one command.

Administrator: PowerShell or Command Prompt
PS> schtasks /Create /TN "centre" /SC ONLOGON /TR "centre -s" /RL LIMITED /F
!

This task starts Centre when you log on. It does not add a session-unlock trigger.

08

Latest changes

Safer startup, shutdown, and diagnostics.

Centre 0.8.2 and 0.8.3 focused on making the listener easier to operate and troubleshoot.

Single listener

A named Windows mutex prevents duplicate centre -s processes in one login session.

Earlier duplicate detection

A duplicate start exits before configuration, logging, or the file observer are initialized.

Graceful shutdown

Keyboard hooks and the configuration observer are cleaned up on terminal or config-triggered shutdown.

Live logging control

Turn file logging on or off through config.json without restarting a valid listener.

Stricter CLI use

Start, list, read-config, and version flags can no longer be combined accidentally.

Consistent ignored presets

Center-all now skips executables listed in ignored_presets.

09

Troubleshooting

When Windows cannot find centre.

A quick PATH check resolves the most common post-install problem.

  1. Close and reopen your terminal after installation.
  2. Run where centre to check whether the executable is available.
  3. If it is still missing, ensure the Python Scripts directory used by pip is included in your PATH.
  4. Confirm the installation with py -m pip show centre.
i

Listener stopped after a save? Check the terminal for JSON or validation details. If logging was already enabled, also inspect %USERPROFILE%\.centre\centre.log. Fix the configuration, then start Centre again.
